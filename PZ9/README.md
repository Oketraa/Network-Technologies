# RoboTaxi

Локальное веб-приложение пассажира беспилотного такси. Экраны, стили, карты и иконки основаны на предоставленном макете ПР9.

## Запуск

Из каталога `RoboTaxi` запустите веб-сервер и Mailpit:

```powershell
.\run.ps1
```

Откройте [RoboTaxi](http://127.0.0.1:8000). Требуется Python 3.11 или новее. При первом запуске скрипт скачивает [Mailpit](https://mailpit.axllent.org/docs/install/) в `.tools/`, если утилиты ещё нет в проекте или в `PATH`. Порт приложения можно изменить через `.\run.ps1 -Port 8080`. Если Mailpit запущен отдельно, достаточно `python main.py`.

Введите российский номер и нажмите «Получить код». На следующем экране откройте уведомления и возьмите шестизначный код из нового письма. [Ящик Mailpit](http://127.0.0.1:8025) принимает уведомления по SMTP на `127.0.0.1:1025`. Код действует пять минут, повторная отправка доступна через 45 секунд. Mailpit перехватывает письма локально. SMS оператору не отправляются.

Для запуска Mailpit вручную используйте `mailpit --smtp 127.0.0.1:1025 --listen 127.0.0.1:8025`. Порты можно задать через `ROBOTAXI_SMTP_PORT` и `ROBOTAXI_INBOX_PORT`. База `data/robotaxi.sqlite3` создаётся при первом запуске. Подтверждённые номера, заказы и обращения сохраняются между запусками.

## Сценарии

- Отметить место посадки и пункт назначения на карте или ввести адреса вручную. После выбора точки приложение подставляет ближайший адрес. Затем выберите время подачи и число пассажиров и рассчитайте поездку.
- Смоделировать прибытие, открыть двери, начать и завершить поездку. До открытия дверей можно отменить заказ. В пути доступна досрочная остановка.
- Посмотреть историю и оставить оценку после поездки.
- Изменить имя, номер, почту и демонстрационный способ оплаты. Новый номер требует повторного подтверждения.
- Открыть частые вопросы, сохранить обращение и найти его в разделе «Мои обращения».
- Скачать журнал из раздела «Поддержка → Журнал действий». Он фиксирует действия и ошибки в браузере. Значения полей форм в журнал не попадают.

Подложка карты загружается с [OpenStreetMap](https://www.openstreetmap.org/copyright). Сервер отправляет в [Nominatim](https://nominatim.org/release-docs/latest/api/Overview/) введённый адрес или координаты выбранной точки. [OSRM](https://routing.openstreetmap.de/) получает координаты двух точек и возвращает линию маршрута, расстояние и время. Подтверждённый маршрут хранится в SQLite и отображается на экранах поездки. Для поиска адресов, новых расчётов и подложки требуется интернет. Подача машины и оплата моделируются локально.

## Структура

| Компонент | Назначение |
| --- | --- |
| `main.py` | Запуск HTTP-сервера, разбор запросов и выдача статических файлов |
| `robotaxi/application.py` | Маршруты экранов, доступ и обработка форм |
| `robotaxi/accounts.py` | Вход, сеансы, профиль и настройки оплаты |
| `robotaxi/notifications.py` | Отправка одноразовых кодов по SMTP |
| `robotaxi/maps.py` | Проверка координат и запрос маршрута у OSRM |
| `robotaxi/orders.py` | Расчёт маршрута и тарифа, назначение автомобиля, состояния заказа и отзывы |
| `robotaxi/support.py` | Создание и просмотр обращений |
| `robotaxi/storage.py` | Схема SQLite и транзакции |
| `robotaxi/views.py`, `templates/` | Экраны и общие компоненты интерфейса |
| `static/` | Стили, иллюстрации, небольшие интерактивные элементы и журнал |

## Проверка

Swagger UI на `/docs` использует cookie текущего сеанса. Войдите через интерфейс на том же адресе или выполните `POST /api/auth/request-code`, затем `POST /api/auth/verify-code` с кодом из Mailpit. Браузер передаёт cookie автоматически, поле Value в Authorize можно оставить пустым.

- `POST /api/orders/quote` рассчитывает поездку. Значение `token` из ответа передайте в поле `quote_token` при вызове `POST /api/orders`.
- `POST /api/tickets` создаёт обращение. В `order_id` можно передать ID своего заказа.
- `POST /api/orders/{id}/cancel` отменяет заказ до открытия дверей.
- `GET /api/me`, `GET /api/orders/{id}` и `GET /api/tickets/{id}` возвращают данные текущего пассажира.
- `POST /api/me/deletion-code` запрашивает отдельный код. Передайте его в заголовке `X-Confirmation-Code` при вызове `DELETE /api/me`. Сервер удалит аккаунт, сеансы, заказы, отзывы и обращения. Пока есть активный заказ, оба запроса возвращают HTTP 409.

Каждый сценарий можно запустить отдельно из каталога `RoboTaxi`.

| Скрипт | Что проверяет |
| --- | --- |
| `python tests/test_auth.py` | Вход через форму и API, подтверждение номера, неверные и истёкшие коды, повторную отправку, выход, профиль и удаление аккаунта |
| `python tests/test_taxi_order.py` | Ввод адресов и выбор точек, время подачи и число пассажиров, расчёт и подтверждение, назначение машины, отмену, обычное и досрочное завершение, отзывы |
| `python tests/test_support.py` | Обращения с заказом и без него, все темы, проверку текста, список и карточку, доступ к своим обращениям |

Запуск всех сценариев вместе.

```powershell
python -m unittest discover -s tests -v
```

Тесты поднимают локальный HTTP-сервер на свободном порту и создают отдельную временную SQLite для каждой проверки. Они отправляют реальные HTTP-запросы к страницам и API RoboTaxi. Вместо внешней доставки писем и запросов к картографическим сервисам используются локальные тестовые ответы.
